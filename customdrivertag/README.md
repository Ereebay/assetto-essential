# Damgam's Custom Driver Tags (Online version)

This scripts is based on [Damgam](https://github.com/Damgam) custom driver tags scrips. I converit to Online script version.

just paste the script url in csp option ini file to use this script
```ini
[SCRIPT_...]
SCRIPT="SCRIPT URL"
```
